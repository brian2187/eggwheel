# Eggwheel

Backyard flock book plus an egg-color pairing wheel.

Track chickens from egg to adult. Record ID, name, photo, source, phone, email, website, dam, sire, and the color each hen actually lays. Tap a color on the wheel to see the breeding recipe and the best pairs from your flock.

## Open it

Repo: https://github.com/brian2187/eggwheel

Turn on GitHub Pages: Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
Live URL after that:

https://brian2187.github.io/eggwheel/

## Data

Records stay in the browser. Use Guide → Export flock before changing phones.

## Genetics used

- Blue gene (oocyan, O) is dominant. One copy makes a blue shell all the way through.
- Brown overlay is polygenic surface pigment.
- Blue + no brown = blue. Blue + light brown = green. Blue + heavy brown = olive. No blue + heavy brown = chocolate.
